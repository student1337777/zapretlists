# Custom Zapret Lists Compilation

Данный репозиторий содержит дополненный список доменов для утилиты **[Zapret](https://github.com/bol-van/zapret)** (адаптированной версии от **[Flowseal/zapret-discord-youtube](https://github.com/flowseal/zapret-discord-youtube)**).

## Содержимое
* **[list-general.txt](list-general.txt)** — объединенный и расширенный список доменов для обхода DPI-блокировок.

## Включенные категории ресурсов:
1. **Видео и стриминг:** YouTube (включая Google Video CDN, `ytimg.com` и др.), Twitch, SoundCloud.
2. **Мессенджеры:** Discord (включая все медиа-сервера и CDN).
3. **Искусственный Интеллект (AI):** ChatGPT/OpenAI, Claude/Anthropic, Copilot, Hugging Face, Gemini.
4. **Игровые платформы:** Steam, Epic Games, EA/Origin, Ubisoft/Uplay, Battle.net, PlayStation Network, Xbox/Xbox Live, Nintendo Network, Roblox, Minecraft, Riot Games.
5. **Игровые форумы, моды и читы:** Nexus Mods, ModDB, CurseForge, UnknownCheats, MPGH, YouGame, Lolzteam (Zelenka/Lolz Guru), Blast.hk.
6. **Торговые площадки:** FunPay, Plati.Market, G2A, Kinguin.
7. **Информационные ресурсы и форумы:** Reddit, Quora, 4PDA, Ru-Board, JoyReactor, Habr.
8. **Инструменты разработчика:** Docker, Intel, NVIDIA, AMD, Visual Studio.
9. **Конфиденциальность:** ProtonMail, Tor Project.
10. **Новостные издания:** BBC, Deutsche Welle, Euronews, Медуза, Радио Свобода, Цензор.НЕТ, Униан и др.

## Инструкция по установке

### Способ: Замена основного списка 
1. Скачайте файл `list-general.txt`.
2. Перейдите в папку с установленным **zapret-discord-youtube** (например, `C:\zapret-discord-youtube\lists\`).
3. Скопируйте скачанный файл `list-general.txt` в эту папку с заменой существующего.
4. Перезапустите службу Zapret (запустите `service.bat` от имени администратора, выберите пункт переустановки/перезапуска службы).
